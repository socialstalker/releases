# SocialStalker Extension Releases

Official release distribution, package binaries (.crx, .zip), and changelogs for the [SocialStalker](https://github.com/socialstalker) Chrome Extension.

SocialStalker is a Manifest V3 Chrome extension for unlocking full-size profile pictures, downloading stories, posts, and reels, and blocking seen receipts on Instagram and Facebook.

## How to Install

### Method 1: Using the .crx file (Recommended)
1. Download the latest social-stalker-*.crx from the [Releases](https://github.com/socialstalker/releases/releases) tab.
2. In Google Chrome, navigate to chrome://extensions/.
3. Enable the **Developer mode** toggle in the top-right corner.
4. Drag and drop the downloaded .crx file anywhere onto the chrome://extensions/ page.
5. Click **Add extension** when prompted.

### Method 2: Using the Unpacked .zip
1. Download the social-stalker-*.zip file.
2. Extract the zip archive to a local folder.
3. Open Chrome and navigate to chrome://extensions/.
4. Turn on **Developer mode**.
5. Click **Load unpacked** and select the extracted folder.
